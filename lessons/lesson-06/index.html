Digital Organization: Files & Documents

Output: Folder Structure + Naming Convention

Step 1 of 9

Learn

Before you start

By the end of this lesson you will be able to:

  • Create logical folder structures.
  • Use clear file naming and versioning.
  • Manage shared documents responsibly.
  • Understand basic file permissions and access.
Key idea

Good digital organization makes information easier to find, harder to misuse, and less likely to be duplicated or lost.

Learn

Folder structure

Organize around how the business retrieves information. Avoid a single "Miscellaneous" folder that becomes a dumping ground.

Learn

File naming

A useful naming convention is predictable and searchable.

YYYY-MM-DD_Client_Project_Document_v01
Learn

Version control

Use a clear method for drafts and final versions. Avoid filenames such as:

final-final2-reallyfinal.xlsx

Learn

Permissions

Give people the access they need for the work, and avoid broad access when narrower access is sufficient.
