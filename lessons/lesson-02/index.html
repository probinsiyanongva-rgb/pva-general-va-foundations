Lesson 2 of 13

The Administrative Workflow: From Request to Done

Output: Client Request → Action Plan

Step 1 of 8

Learn

Before you start

By the end of this lesson you will be able to:

  • Turn a client request into an action plan.
  • Identify missing information.
  • Ask useful clarification questions.
  • Determine priority, dependencies, and deadlines.
  • Verify work before reporting completion.
Key idea

Use the eight-stage workflow for every request, big or small:

RECEIVE→ UNDERSTAND→ CLARIFY→ PLAN→ EXECUTE→ CHECK→ REPORT→ CLOSE
Learn

Receive → Understand

STAGE 1 — RECEIVE

Read the request carefully. Identify what, why, when, where, who, and how.

STAGE 2 — UNDERSTAND

Identify the desired outcome, not just the literal action. "Clean this up" is incomplete unless you know what clean means.

Learn

Clarify → Plan

STAGE 3 — CLARIFY

Ask specific questions about decisions that affect the outcome. Good questions are necessary, concise, and easy to answer.

STAGE 4 — PLAN

Identify priority, deadline, dependencies, required tools, information, and approval requirements.

Learn

Execute → Check

STAGE 5 — EXECUTE

Perform the work according to the instructions and any relevant SOP. Do not silently invent decisions outside your authority.

STAGE 6 — CHECK

Review accuracy, completeness, format, links, file version, privacy, and whether the requested outcome was achieved.

Learn

Report → Close

STAGE 7 — REPORT

Tell the client what was completed, what matters, what is pending, and the next step when relevant.

STAGE 8 — CLOSE

Update the task tracker, folder, calendar, follow-up list, or other system so the work does not remain mentally open.

Practice

Write your clarification questions

"Can you organize the attached contacts spreadsheet and have it ready by tomorrow? Thanks!"

What is known? There is a contacts spreadsheet, it needs organization, there is a deadline, and the client expects a completed file.
What may be unclear? What "organize" means, how duplicates should be handled, the required format, where the file should be saved, and the actual deadline time.

Suggested answers: (1) Which fields should be standardized, and is there an existing format? (2) Should duplicates be removed or flagged? (3) Is there a required folder and naming convention?
Practice → Decide

Spot the skipped stage

A VA finishes cleaning a client's spreadsheet and immediately messages: "Done! Let me know if you need anything else." The file actually has three blank required fields the VA didn't notice.

Which stage of the workflow did the VA skip?
