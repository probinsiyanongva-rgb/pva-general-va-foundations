Learn

Before you start

By the end of this lesson you will be able to:

  • Recognize personal and confidential information.
  • Use safer access practices.
  • Understand least-privilege access.
  • Apply basic password, MFA, and device security habits.
  • Respond appropriately to a suspected security issue.
Key idea

Client trust includes information security. Convenience is not a good reason to weaken access controls.

Learn

Basic security practices

  • Use strong, unique credentials and MFA where available.
  • Prefer delegated access over sharing master passwords when a platform supports it.
  • Use only the access needed for the task.
  • Do not download or copy sensitive information unnecessarily.
  • Keep devices and software updated.
  • Be cautious with public or shared devices and networks.
  • Follow the client's retention and deletion rules.
  • Remove access when work ends, according to the client's offboarding process.
Learn

Philippine context

When working from the Philippines, handling personal information should be consistent with applicable privacy requirements, including the Data Privacy Act of 2012 (Republic Act No. 10173) and relevant National Privacy Commission guidance.

This course is not legal advice; learners should follow the client's policies and applicable law.
