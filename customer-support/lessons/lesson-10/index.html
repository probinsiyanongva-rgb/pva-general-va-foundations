Before you start

By the end of this lesson you will be able to:

  • Understand common support metrics.
  • Distinguish speed from quality.
  • Use simple metrics to understand workload.
  • Recognize why one metric can create bad behavior.
  • Connect ticket quality to customer outcomes.
Key idea

A fast response is useful only if it is accurate and moves the case toward resolution.

Learn

Common support metrics

MetricMeaning
First response timeTime customers wait for the first response
Resolution/handle timeTime needed to handle or resolve a case
First contact resolutionCases resolved without additional contacts
CSATCustomer satisfaction after an interaction
BacklogOpen cases awaiting action
Escalation rateShare of cases moved to another level/team
